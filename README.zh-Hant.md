# PhoneRecord — 通話錄音工作台

x64 開發版新增可選的[離線錄音轉文字](docs/離線錄音轉文字.md)：預設關閉，一鍵安裝本機環境；通話中以 SenseVoiceSmall INT8 陸續出字，掛斷後可用 Qwen3-ASR 0.6B／1.7B 重轉並保留兩版結果。支援歷史錄音手動轉寫；x86 不包含此功能。可選的[通話 AI 分析](docs/通話AI分析.md)可關聯專案、選擇 CLI 與提示詞，結合多份轉寫整理摘要／需求；內容可能傳送至 CLI 提供者。

目前 C++ 桌面原始碼版本為 **2.7.7**。在 Windows 接收相容話機的網路錄音，接通後自動錄製、掛斷後保存，並提供內建播放、健康檢查與故障建議。
2.7.6 支援話機 DHCP 自動追蹤：首次填寫目前 IP 與 MAC，儲存重啟後一鍵設定；之後依回呼換址，不再依賴固定 IP。
2.7.7 在 DHCP 下保留原有啟動完成與 IP 變更地址，通話中直接顯示即時字幕，並把字幕和錄音轉寫存成可開啟的文字檔；通話 AI 分析改為按一條設定新增和修改。
2.7.4 預設帶入本機 IPv4，填寫話機 IP 後依路由更新未手改的建議，保留已保存或手動填寫的位址。
2.7.2 加入「連接設定 → 一鍵設定話機」：預覽並確認後直接配置 Network 錄音與通話回呼，保留加密備份及回讀驗證；無需產生或執行腳本。參閱[操作手冊 PDF](output/pdf/PhoneRecord_操作與設定手冊.pdf)。
2.7.0 加入[自動更新](docs/自動更新與發布.md)：背景定時檢查、獨立更新氣泡與托盤箭頭標識；由使用者下載並在空閒時確認重啟安裝。首次需手動安裝具備更新能力的版本，正式檔案以 [GitHub Releases](https://github.com/ChenRanReal/PhoneRecord/releases) 為準。
2.6.0 加入歷史通話重新命名：在錄音資料選取紀錄，點「重新命名」或按 F2，自訂名稱可搜尋並在重開後保留。留空保存可還原原名，原始號碼、時間、聯絡人及錄音檔保留。
2.5.0 加入可自行關閉的開機啟動：設定頁勾選或取消立即生效，預設關閉；開啟後於登入時在托盤背景執行。移動 exe 後請關閉並重新開啟以更新路徑。
2.4.1 加入話機設定腳本：先預覽，確認後設定網路錄音及兩條回呼，回讀驗證並保留加密備份。保留原創圖示與三語介面。

## 啟動與首次設定

在本專案雙擊 [Start-PhoneRecord.cmd](Start-PhoneRecord.cmd)，或直接執行 `cpp/PhoneRecord.exe`。
交給其他使用者時，exe 可以單獨啟動，不需要 Python；放入可寫入的資料夾，首次會開啟設定頁，必要位址與帳號留空，讓使用者填自己的資料。
可選的 [config.example.ini](cpp/config.example.ini) 是空白範本，不能使用目前電腦的個人設定檔代替。

左下可切換簡體中文、繁體中文及 English；完整離線說明已內建，包括首次設定、每個欄位用途與電話端對照。
連接設定保存後，請按左下「退出程式」再重開；右上 X 預設只是收至托盤。

若登入檢查通過但接通後未錄音，先看 [話機自動設定](docs/話機自動設定.md)。話機端仍需設定 Network、錄音目的地及兩條通話回呼；請在「連接設定」按「一鍵設定話機」。

## 主要功能

| 頁面 | 用途 |
|---|---|
| 運行概覽 | 自動錄音、獨立本機／話機健康燈、錄音鏈路及可跟隨最新事件的時間線 |
| 錄音資料 | 通話名稱／聯絡人／號碼／日期搜尋、重新命名及還原原名、程式內播放／暫停／拖曳進度、定位檔案及訊號檢查 |
| 診斷中心 | 毫秒事件與穩定代碼、逐項處理建議、複製／匯出報告 |
| 連接設定 | 正整數埠、逐欄說明、保存目錄、健康頻率、關閉方式、氣泡通知與開機啟動 |
| 說明與適配 | 三語首次上手、通用回呼模板、唯讀適配檢查及不列實際 IP 的適配報告 |

通訊錄會在登入後及閒置時自動同步，也可在「錄音資料」按「同步話機通訊錄」，讓只有號碼的通話顯示可比對的姓名。詳見 [話機通訊錄同步](docs/話機通訊錄同步.md)。

托盤氣泡預設關閉，可由使用者自行開啟。檢查不改寫電話，也不試打或觸發錄音；「設定匹配」後仍須完成約 20 秒真實通話並試聽雙方聲音。

## 適配與埠

已驗證組合：Fanvil X3S，硬體 V1.1，韌體 2.4.7.9.1。其他型號先檢查網頁與錄音協議，不能只憑品牌或 SIP 能力判定相容。
目前支援 Network 伺服器錄音、PCMA／PCMU 8kHz，電話須提供雙向混音。

| 用途 | 預設值 | 電話端對應 |
|---|---|---|
| 話機網頁 HTTP | 80 | 電話實際管理網頁埠 |
| 錄音控制 TCP | 10000 | 錄音伺服器埠 |
| 通話事件 TCP | 18080，可調整 | 兩條 Action URL 中的事件埠 |
| 音訊 UDP | 20000–20100 | 話機向電腦送音訊的範圍 |

所有位址都由使用者自行填寫。修改事件埠時須同步兩條電話回呼；一般設定保存不會自動改寫話機。
