# PhoneRecord — 通话录音工作台

x64 开发版新增可选的[离线录音转文字](docs/離線錄音轉文字.md)：默认关闭，一键安装本机环境；通话中使用 SenseVoiceSmall INT8 持续输出文字，挂断后可用 Qwen3-ASR 0.6B／1.7B 重转并保留两版结果。支持历史录音手动转写；x86 不包含此功能。可选的[通话 AI 分析](docs/通話AI分析.md)可关联项目、选择 CLI 与提示词，结合多份转写整理摘要／需求；内容可能发送至 CLI 提供者。

当前 C++ 桌面源码版本为 **2.7.7**。在 Windows 接收兼容话机的网络录音，接通后自动录制、挂断后保存，并提供内建播放、健康检查与故障建议。
2.7.6 支持话机 DHCP 自动追踪：首次填写当前 IP 与 MAC，保存重启后一键设置；之后按回调换址，不再依赖固定 IP。
2.7.7 在 DHCP 下保留原有启动完成与 IP 变更地址，通话中直接显示实时字幕，并把字幕和录音转写存成可打开的文本文件；通话 AI 分析改为按一条配置新增和修改。
2.7.4 默认带入本机 IPv4，填写话机 IP 后按路由更新未手改的建议，保留已保存或手动填写的地址。
2.7.2 增加「连接设置 → 一键设置话机」：预览并确认后直接配置 Network 录音与通话回调，保留加密备份及回读验证；无需生成或执行脚本。参阅[操作手册 PDF](output/pdf/PhoneRecord_操作與設定手冊.pdf)。
2.7.0 加入[自动更新](docs/自動更新與發布.md)：后台定时检查、独立更新气泡与托盘箭头标识；由用户下载并在空闲时确认重启安装。首次需手动安装具备更新能力的版本，正式文件以 [GitHub Releases](https://github.com/ChenRanReal/PhoneRecord/releases) 为准。
2.6.0 增加历史通话重命名：在录音资料选择记录，点击「重命名」或按 F2，自定义名称可搜索并在重开后保留。留空保存可还原原名，原始号码、时间、联系人及录音文件保留。
2.5.0 增加可自行关闭的开机启动：设置页勾选或取消立即生效，默认关闭；开启后在登录时于托盘后台运行。移动 exe 后请关闭并重新开启以更新路径。
2.4.1 加入话机设置脚本：先预览，确认后设置网络录音及两条回调，回读验证并保留加密备份。保留原创图标与三语界面。

## 启动与首次设置

在本项目双击 [Start-PhoneRecord.cmd](Start-PhoneRecord.cmd)，或直接运行 `cpp/PhoneRecord.exe`。
交给其他用户时，exe 可以单独启动，不需要 Python；放入可写入的文件夹，首次会打开设置页，必要地址与账号留空，让用户填写自己的资料。
可选的 [config.example.ini](cpp/config.example.ini) 是空白模板，不能使用当前电脑的个人配置文件代替。

左下可切换简体中文、繁體中文及 English；完整离线说明已内建，包括首次设置、每个字段用途与电话端对照。
连接设置保存后，请按左下「退出程序」再重开；右上 X 默认只是收起到托盘。

若登录检查通过但接通后未录音，先看 [话机自动设置](docs/話機自動設定.md)。话机端仍需设置 Network、录音目的地及两条通话回调；请在「连接设置」点击「一键设置话机」。

## 主要功能

| 页面 | 用途 |
|---|---|
| 运行概览 | 自动录音、独立本机／话机健康灯、录音链路及可跟随最新事件的时间线 |
| 录音资料 | 通话名称／联系人／号码／日期搜索、重命名及还原原名、程序内播放／暂停／拖动进度、定位文件及讯号检查 |
| 诊断中心 | 毫秒事件与稳定代码、逐项处理建议、复制／导出报告 |
| 连接设置 | 正整数端口、逐字段说明、保存目录、健康频率、关闭方式、气泡通知与开机启动 |
| 帮助与适配 | 三语首次上手、通用回调模板、只读适配检查及不列实际 IP 的适配报告 |

通讯录会在登录后及空闲时自动同步，也可在「录音资料」点击「同步话机通讯录」，为只有号码的通话显示匹配姓名。详见 [话机通讯录同步](docs/話機通訊錄同步.md)。

托盘气泡默认关闭，可由用户自行开启。检查不改写电话，也不试打或触发录音；「设置匹配」后仍须完成约 20 秒真实通话并试听双方声音。

## 适配与端口

已验证组合：Fanvil X3S，硬件 V1.1，固件 2.4.7.9.1。其他型号先检查网页与录音协议，不能只凭品牌或 SIP 能力判定兼容。
当前支持 Network 服务器录音、PCMA／PCMU 8kHz，电话须提供双向混音。

| 用途 | 默认值 | 电话端对应 |
|---|---|---|
| 话机网页 HTTP | 80 | 电话实际管理网页端口 |
| 录音控制 TCP | 10000 | 录音服务器端口 |
| 通话事件 TCP | 18080，可调整 | 两条 Action URL 中的事件端口 |
| 音频 UDP | 20000–20100 | 话机向电脑送音频的范围 |

所有地址都由用户自行填写。修改事件端口时须同步两条电话回调；一般设置保存不会自动改写话机。
