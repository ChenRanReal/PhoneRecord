# PhoneRecord — 通话录音工作台

当前 C++ 桌面版本为 **2.4.1**。在 Windows 接收兼容话机的网络录音，接通后自动录制、挂断后保存，并提供内建播放、健康检查与故障建议。
2.4.1 加入话机设置脚本：先预览，确认后设置网络录音及两条回调，回读验证并保留加密备份。保留原创图标与三语界面。

[下载 Windows 程序](https://github.com/ChenRanReal/PhoneRecord/raw/refs/heads/main/cpp/PhoneRecord.exe) · [图标与资产](cpp/assets/README.md)

**第一次使用请从 [快速上手](docs/快速上手.md) 开始**，依次完成电脑设置、电话设置、适配检查与双向试听。[English quick start](docs/QuickStart.en.md) is also available.

## 启动与首次设置

在本项目双击 [Start-PhoneRecord.cmd](Start-PhoneRecord.cmd)，或直接运行 `cpp/PhoneRecord.exe`。
交给其他用户时，exe 可以单独启动，不需要 Python；放入可写入的文件夹，首次会打开设置页，必要地址与账号留空，让用户填写自己的资料。
可选的 [config.example.ini](cpp/config.example.ini) 是空白模板，不能使用当前电脑的个人配置文件代替。

左下可切换简体中文、繁體中文及 English；完整离线说明已内建，包括首次设置、每个字段用途与电话端对照。
连接设置保存后，请按左下「退出程序」再重开；右上 X 默认只是收起到托盘。

若登录检查通过但接通后未录音，先看 [话机自动设置](docs/話機自動設定.md)。话机端仍需设置 Network、录音目的地及两条通话回调；新版本可自行生成脚本。

## 主要功能

| 页面 | 用途 |
|---|---|
| 运行概览 | 自动录音、独立本机／话机健康灯、录音链路及可跟随最新事件的时间线 |
| 录音资料 | 姓名／号码／日期搜索、程序内播放／暂停／拖动进度、定位文件及讯号检查 |
| 诊断中心 | 毫秒事件与稳定代码、逐项处理建议、复制／导出报告 |
| 连接设置 | 正整数端口、逐字段说明、保存目录、健康频率、关闭方式与气泡通知偏好 |
| 帮助与适配 | 三语首次上手、通用回调模板、只读适配检查及不列实际 IP 的适配报告 |

托盘气泡默认关闭，可由用户自行开启。检查不改写电话，也不试打或触发录音；「设置匹配」后仍须完成约 20 秒真实通话并试听双方声音。

## 适配与端口

已验证组合：Fanvil X3S，硬件 V1.1，固件 2.4.7.9.1。其他型号先检查网页与录音协议，不能只凭品牌或 SIP 能力判定兼容。
当前支持 Network 服务器录音、PCMA／PCMU 8kHz，电话须提供双向混音。

| 用途 | 默认值 | 电话端对应 |
|---|---|---|
| 话机网页 HTTP | 80 | 电话实际管理网页端口 |
| 录音控制 TCP | 10000 | 录音服务器端口 |
| 通话事件 TCP | 18080，可调整 | 两条 Action URL 中的事件端口 |
| 音频 UDP | 20000–20100 | 话机向电脑送音频的范围 |

所有地址都由用户自行填写。修改事件端口时须同步两条电话回调；一般设置保存不会自动改写话机。
