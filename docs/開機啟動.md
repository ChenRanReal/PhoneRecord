# 開機啟動與舊版入口

PhoneRecord 2.5.0 的「連接設定 → 開機啟動（背景）」預設關閉。勾選或取消立即更新 Windows 啟動項，不用按保存，亦不改動連接設定草稿。這是目前 Windows 使用者的設定，交付 exe 或 `config.ini` 不會替其他使用者自動開啟。

## 使用方式

1. 將 exe 放在固定、可寫入的位置，完成自己的話機設定並驗收錄音。
2. 勾選「開機啟動（背景）」。下次登入 Windows 後，會使用目前的 exe 與設定檔於系統托盤執行；雙擊托盤圖示可開啟主視窗。
3. 取消勾選即移除此程式的啟動登記，下次登入不由這個項目啟動。現在執行中的程式繼續錄音，需結束時另按「退出程式」。
4. 移動 exe 或設定檔後，在新位置取消並重新勾選，以更新啟動路徑。若偵測到另一位置的登記，欄位說明會提示。

背景啟動保留錄音服務與可還原的主視窗，不使用純命令列模式。若設定未完成或系統托盤建立失敗，會顯示視窗以便處理。重複的自動啟動會自行結束，不額外彈出「已在執行」視窗。

若 Windows「啟動應用程式」或工作管理員另行停用此項，請於 Windows 中重新允許。程式會回讀啟動登記，並顯示權限／路徑過長等錯誤；不修改系統管理原則。程式或電腦在關機、休眠、退出期間仍無法錄音。

## 舊版仍會彈出時

新版開關只管理本身建立的 Windows 啟動項。舊版手動建立的 BAT、捷徑或工作排程是獨立入口，應確認目標後另行移除：

- 按 Win+R，輸入 `shell:startup`，查看目前使用者啟動資料夾；先備份，只移除指向舊版的 `PhoneRecord.bat` 或捷徑。
- 在工作管理員或 Windows 設定的「啟動應用程式」查看 PhoneRecord 項目。
- 若曾手動建立排程，在工作排程器確認名稱及執行目標，只移除自己的 PhoneRecord 排程。

不需要刪除錄音、聯絡人或連接設定，也不必移除其他程式的啟動項。

## 開發對照

登記位於目前使用者 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值名 `PhoneRecord`，以含引號的 exe／設定檔絕對路徑直接執行 `--startup`；不經 shell、不含帳密。取消僅刪除這一個值，不刪整個 Run key。

Windows 在登入時處理 Run 項目，可能延後啟動；文件規定命令最多 260 字元，程式會先拒絕超限路徑。參考 [Microsoft Run / RunOnce 文件](https://learn.microsoft.com/windows/win32/setupapi/run-and-runonce-registry-keys)。
