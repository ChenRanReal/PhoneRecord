# 話機自動設定：連線檢查成功，為何仍不錄音？

話機登入成功只證明電腦能讀取管理網頁。自動錄音另外需要電話端的 **Network 網路錄音設定**，以及 **通話建立／結束的兩條 Action URL**。錄音在對方接聽後開始，撥號或振鈴本身不觸發錄音。

PhoneRecord 2.4.0 可從 exe 自行產生設定腳本，使用 Windows PowerShell 5 或更新版本，不需要安裝 Python。腳本供這台電腦目前保存的設定使用；其他人應在自己的電腦重新產生。

## 同事怎麼使用

1. 使用新版 `PhoneRecord.exe`，在「連接設定」填自己的電話 IP、網頁埠、帳密、本機可達 IPv4 及埠。自動設定需要具有**錄音管理寫入權限**的網頁帳號，與 SIP 分機帳號不同。
2. 保存設定，按左下「退出程式」再重開，讓目前設定生效。右上 X 預設只收至托盤。
3. 點「產生話機設定腳本」，選擇保存 `.cmd`。
4. 確認沒有通話或錄音，從左下退出程式，再雙擊剛產生的 CMD。
5. 腳本先讀取並列出變更及目標話機；確認後輸入大寫 `APPLY` 才會套用。其他輸入取消。設定已匹配時直接略過寫入。
6. 成功回讀後，腳本重新開啟程式。接通約 20 秒，雙方輪流說話，掛斷後播放最新錄音，確認雙向聲音。

腳本使用同目錄配置及目前 Windows 使用者的加密帳密；腳本本身不包含密碼或 cookie。請交給同事新版 exe 與指南，讓他填自己的資料；不要把你的配置或已產生腳本當成別人的設定範本。

## 會設定哪些欄位

| 話機設定 | 對應值 |
|---|---|
| 啟用錄音 | 啟用 |
| 錄音類型 | Network |
| 錄音編碼 | PCMA；已選 PCMU 時保留 PCMU |
| 錄音伺服器位址 | 程式保存的「本機可達 IPv4」 |
| 錄音伺服器埠 | 程式保存的 TCP 控制埠，預設 10000 |
| Call Established | `http://<PC_IP>:<EVENT_PORT>/event?ev=est` |
| Call Terminated | `http://<PC_IP>:<EVENT_PORT>/event?ev=end` |

事件埠預設 18080，與錄音伺服器埠不同。腳本保留可識別的舊錄音回呼參數，例如話機巨集；若目標事件已有其他公司用途的回呼，會以 `SETUP_CALLBACK_CONFLICT` 停止，由管理員安排轉送。其他已讀取的欄位會保留並回讀比對。

目前自動套用僅針對已支援的 Fanvil 網路錄音欄位與選項介面。未知欄位契約、未支援選項、正在錄音或使用外部觸發模式時會停止；不能只憑品牌認定相容。

## 備份、失敗與還原

套用前，程式將完整已讀取表單加密保存至配置目錄的 `phone-setup-backups/`。備份綁定目前 Windows 使用者與目標電話；不保存明文表單。
預覽編號也會綁定當時的表單與目的地；預覽後若設定改變，需重新預覽。

| 代碼 | 處理方式 |
|---|---|
| `SETUP_CLOSE_APPLICATION` | 從左下退出程式後再執行；X 通常未退出 |
| `SETUP_LOCAL_NOT_READY` | 核對本機網卡與埠是否被其他實例占用 |
| `SETUP_AUTH_FAILED` | 檢查網頁帳密、埠與權限 |
| `SETUP_WRITE_DENIED` | 帳號可登入但無修改權限，換有錄音管理權限的帳號 |
| `SETUP_CALLBACK_CONFLICT` | 目標事件已有其他用途，請管理員安排轉送 |
| `SETUP_UNSUPPORTED` | 目前網頁／選項尚未適配，改用手動設定並記錄型號與韌體 |
| `SETUP_PLAN_STALE` | 重新執行預覽，不沿用過期編號 |
| `SETUP_FAILED_RESTORED` | 套用失敗，已回讀確認原設定恢復；依失敗原因修正 |
| `SETUP_FAILED_RESTORE_REQUIRED` | 未能確認還原；保留備份與日誌，無通話時執行還原命令 |
| `SETUP_BACKUP_INVALID` | 備份損壞、Windows 使用者不同或電話目標不符 |

一般使用腳本即可。需要人工還原時，先退出程式、保持無通話，在命令列使用自己的配置與備份路徑：

```powershell
$process = Start-Process .\PhoneRecord.exe -ArgumentList '--config ".\config.ini" --phone-setup-restore ".\phone-setup-backups\YOUR_BACKUP.dpapi" --setup-report ".\phone-setup-report.json"' -Wait -PassThru -WindowStyle Hidden
Get-Content .\phone-setup-report.json -Raw -Encoding UTF8
```

還原前會另存目前狀態的加密備份，再回讀確認。設定腳本及還原命令不發送錄音 Start／Stop，不更改 SIP、帳密、公司其他回呼或 Windows 防火牆。

## 設定通過後仍不錄音

設定回讀不等於端到端錄音驗收。保持電腦喚醒、程式運行，接通真實電話後看「本次錄音鏈路」與診斷事件：

| 停在哪裡 | 檢查 |
|---|---|
| 沒有 `EVENT_RECEIVED` | 兩條回呼是否保存、電話能否到達電腦事件埠、Windows 防火牆是否允許此 exe；`EVENT_SOURCE_REJECTED` 則核對來源與電話 IP |
| 有事件但沒有 TCP | 錄音伺服器位址／控制埠、Network 模式、帳號權限及控制 TCP 是否可達 |
| 有控制回應但沒有音訊 | PCMA／PCMU、UDP 範圍、防火牆及跨網段路由 |
| 有 WAV 但沒聲音或單向 | 播放最新檔，確認話機是否提供雙向混音；不能只看「已保存」 |

有管理策略的電腦可由 IT 放行此 exe 的控制／事件 TCP 與音訊 UDP。腳本只處理電話端設定，網路連通性與雙向語音仍需實測。
