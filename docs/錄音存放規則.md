# 錄音存放規則

入口：「連接設定 → 偏好設定 → 錄音分資料夾」。根目錄仍在「基本設定 → 錄音保存目錄」選擇。

| 方式 | 新錄音位置示例 |
|---|---|
| 不分資料夾（預設） | `recordings/檔名.wav` |
| 每天 | `recordings/2026-11-06/檔名.wav` |
| 每週 | `recordings/2026-11-02/檔名.wav`，以週一日期命名 |
| 自訂 `{yyyy}/{MM}/{dd}` | `recordings/2026/11/06/檔名.wav` |
| 自訂 `週錄音/{weekStart}` | `recordings/週錄音/2026-11-02/檔名.wav` |

自訂支援 `{yyyy}`、`{MM}`、`{dd}`、`{weekStart}`，可搭配文字和 `/` 或 `\` 分層。畫面只預覽，不建立目錄；真正有錄音時才建立。

保存後，無通話時按左下「退出程式」並重開。規則以開始錄音時的本機日期為準，跨午夜不拆檔。每週固定以週一為首日，跨年仍以該週週一日期命名，例如 2026-01-01 屬於 `2025-12-29`。

舊錄音不移動。清單同時讀取根目錄和最多 8 層子目錄，依錄音時間排序，支援搜尋、播放、F2 改名、右鍵分析與定位檔案。不同分類方式可共存在同一根目錄。

WAV、`.quality.json`、`.title.json` 保持相鄰；根目錄 `calls.csv` 的 file 欄以相對路徑記錄，例如 `2026-11-06\檔名.wav`。備份請包含整個根目錄及設定檔。

INI 設定：`record_folder_mode=flat|daily|weekly|custom`；`record_folder_pattern={yyyy}/{MM}/{dd}`。舊版設定缺少這兩項時維持平放。切換預設方式會保留自訂草稿。儲存時驗證目前自訂規則，拒絕絕對路徑、`..`、Windows 保留名稱、非法字元和超過 8 層的路徑；不沿子目錄的 junction／symbolic link 寫入或讀取。

## 驗證

- `pwsh -File tools/Test-RecordingStorage.ps1`：實際 C++ 日期展開，含閏日、跨年、週日／週一及無效格式。
- `python tests/recording_storage_smoke.py --exe <隔離編譯的 exe> --output tmp/storage-tests`：loopback RTP 寫入四種目錄、台帳相對路徑、舊檔共存、排序、巢狀改名／搜尋／播放／重啟、草稿保留、無效值定位和保存重啟邊界。
- 搭配既有 product、recording title、compact UI 回歸測試。此驗證只使用合成資料，沒有操作實體話機。

## 國際化與多語言交付

沿用簡體中文、繁體中文與 English。新欄位、選項、格式說明、預覽及錯誤皆有三語資源；日期資料夾使用固定數字格式，星期規則不隨介面語言改變。語言切換保留分類和自訂草稿；最小視窗已檢查三語排版。PDF 手冊以繁體中文同步更新。
