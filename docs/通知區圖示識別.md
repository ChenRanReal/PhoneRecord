# 通知區圖示識別

PhoneRecord 使用依執行檔完整路徑產生的穩定 GUID 識別通知區圖示，避免原先只依視窗 Handle 與數字 ID 識別時，版本更新重新啟動造成 Windows 顯示偏好無法延續。GUID 不包含版本、執行檔內容、語言或視窗 Handle；新增、修改、通知、移除及 Explorer 重建圖示時均使用相同識別。

自動更新沿用既有 `ReplaceFileW` 原路徑替換與重新啟動流程。不同路徑的可攜副本各自擁有識別，避免 Windows 將同一 GUID 綁定其他執行檔路徑。無法產生 GUID 時記錄 `TRAY_STABLE_IDENTITY_FAILED`，並保留既有圖示行為。

首次從舊版切換至 GUID 識別後，可能需再將圖示從隱藏區拖至通知區一次。之後保持相同執行檔路徑與檔名更新，讓 Windows 沿用顯示偏好；搬移資料夾或重新命名會產生不同識別。程式不改寫 Windows 的通知區偏好或強制顯示其他圖示。

## 驗證

`tests/tray_identity_smoke.py` 以隔離執行檔向真實 Windows Shell 查詢 GUID，涵蓋啟動、更新頁圖示刷新、重建訊息、隱藏與恢復、結束清理，以及替換執行檔內容後重新啟動。測試不操作使用者正在運行的程式。

手動驗收：將修正版圖示拖出隱藏區，保持路徑及檔名更新至後續版本，確認仍在通知區顯示；再重新啟動 Explorer 確認圖示及右鍵選單正常。自動化查詢不能代替跨正式版本更新後顯示位置的人工驗收。

## 國際化與多語言交付

適用原生 Windows 桌面客戶端。既有簡體中文、繁體中文及 English 資源、預設語言、語言選擇來源與缺漏翻譯行為維持既有設計；本次沒有新增顯示文字或資源 Key。圖示識別不依語言改變。既有三語更新頁測試須繼續通過。
