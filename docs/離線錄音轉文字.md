# 離線錄音轉文字（x64）

## 範圍與使用方式

本功能只在 x64 提供。左側分為「即時字幕」與「錄音轉寫」，各自固定顯示設定與文字；連接設定及頁面頂部沒有「模型與設定」等跨頁捷徑。開啟即時字幕後，錄音時在螢幕工作區右下角顯示帶有程式圖示的字幕框，不切換主視窗頁面；每一段辨識完成即寫入該錄音旁的 `.transcript.txt`，並同時寫成可直接開啟的 `錄音名.live.txt`。錄音轉寫完成後另存 `錄音名.qwen.txt` 或 `錄音名.qwen17.txt`。掛斷後這些檔與錄音留在一起，可在錄音資料對該筆右鍵「查看即時字幕」，或「開啟即時字幕檔」「開啟轉寫檔」。錄音右鍵只保留一個「錄音轉寫」，帶入目前選取錄音；移除重複的轉寫／查看入口與跨模組停止全部項目。x86 不顯示兩個入口。三語名稱為 实时字幕／即時字幕／Live captions、录音转写／錄音轉寫／Recording transcription。

### 即時字幕：本機輸入法或 SenseVoice

即時字幕仍預設可關閉。總開關之下先選「本機輸入法」或「本機 SenseVoice」，不會因為有網路就自動改選。本機輸入法只列目前已安裝且已啟用的文字服務，顯示名稱用系統原文；是否支援只看程式內的支援表。支援表目前有五個輸入法：微信（`wetype`，TIP `{86598FB9-66A2-463E-B9C2-AEB906D477AD}`、語言設定 `{607FDF85-FCC8-4DBD-A365-41296F980C9C}`）、豆包（`doubao`）、訊飛（`iflytek`）、搜狗（`sogou`）與 Windows 語音（`windows`），全部以 TIP／語言設定 GUID 辨識。已安裝但不在表內的輸入法仍顯示並標「暫不支援」，不能啟動語音鏈路。沒有受支援的已安裝輸入法時，本機 SenseVoice 仍可選用。

選本機輸入法時，左欄只留輸入法、播放裝置、依賴與網路說明，以及目前狀態；隱藏模型安裝、下載來源與 SenseVoice 型號列。選本機 SenseVoice 時，保留原有語言、來源與安裝。右欄仍然只顯示字幕。

輸入法模式把錄音執行緒的 8 kHz 單聲道 PCM 放進約 2 秒佇列（滿了丟最舊，不阻塞 RTP），由獨立執行緒依裝置時鐘播放到使用者選的虛擬播放端，線性升到該裝置混音格式；欠載補靜音，不送到喇叭，也不改 Windows 預設錄音或播放裝置。虛擬聲卡驅動不放進倉庫或安裝包。面板由程式自己開：先用該輸入法自己的語音快捷鍵；開檔轉寫會先關掉上一輪留下的面板（那時已停止聆聽）再送鍵，四秒內沒出現就再送一次。面板沒出現就不播放，只在左欄以紅字說明。面板文字取自螢幕像素（`PrintWindow` 對 Flutter 面板只得到黑框），並濾掉視窗標題、快捷鍵提示與按鈕字樣。播放結束、掛斷或使用者按停止後，程式關閉面板，輸入法隨即停止錄音。辨識文字不送進其他程式。開始時沒有網路、沒有選中受支援的輸入法，或播放中一段有界時間沒有新文字，這一通改由 SenseVoice 讀同一份正在增長的 WAV。掛斷後先補約 0.8 秒靜音再收尾。同一通只寫既有的 `錄音名.live.txt`、`錄音名.wav.transcript.txt` 與 `錄音名.wav.transcript.json`；輸入法結果不與 SenseVoice 斷點續跑混用，也不改寫 Qwen 檔。

### 即時字幕：SenseVoice

左欄在選本機 SenseVoice 時提供開啟通話字幕、固定 SenseVoiceSmall INT8、獨立辨識語言與下載來源，以及「安裝模型與環境」。右欄只顯示目前通話字幕。收到實際音訊後才提示正在錄音，掛斷時補完尾段；錄音接收不等待推論。關閉字幕不會取消 Qwen 歷史工作。未開啟時，手動安裝 SenseVoice 不會自動開啟通話字幕。

### 錄音轉寫：Qwen

錄音轉寫與即時字幕各自開關，預設關閉。勾選「開啟錄音轉寫」後才能安裝 Qwen 模型並按「開始轉寫」；關閉時不下載、不加入轉寫工作。在本頁選錄音、Qwen3-ASR 0.6B／1.7B、獨立語言與來源。右側版本選單可查看原有 SenseVoice、Qwen 0.6B、Qwen 1.7B 結果，三者分開保存。錄音資料的右鍵「錄音轉寫」會帶入此頁選取的錄音，不會在背景偷偷加入工作。

「電腦配置建議」在同頁顯示模型大小、預留空間、配置估算與本機資訊；再按「返回文字」回到字幕／結果。每個模組的停止按鈕只停止所選模型的工作。安裝錯誤會在所屬模組同頁顯示具體原因，並可返回文字、複製診斷。切換模組不取消工作，已下載模型、已保存文字與舊設定保留；舊版 enabled 設定會沿用為即時字幕開關，新增獨立 liveEnabled、liveLanguage、liveSource 欄位。

## 安裝、依賴與權限

最低語音執行環境為 Windows 10 x64；其他 CPU／OS 組合未承諾支援。x86 錄音版仍沿用原本相容範圍。

依賴存放於 `%LOCALAPPDATA%\PhoneRecord\speech-v1`，不註冊 Windows Service、不改防火牆、不使用全域 Node／npm，SenseVoice 不需 Python；Qwen 使用私有 Python CPU 環境，兩者都不需 GPU、編譯器或系統層套件安裝。因此目前這條安裝路徑不要求 UAC。沒有寫入權限時明確報錯；不將整個主程式改為管理員執行。

|---|---|
| Node x64 | 24.11.0，官方 Windows ZIP，SHA-256 `1054540bce22b54ec7e50ebc078ec5d090700a77657607a58f6a64df21f49fdd` |
| sherpa-onnx-node / sherpa-onnx-win-x64 | 1.13.8，各自固定 npm SHA-512，原生套件含 ONNX Runtime |
| model.int8.onnx | 239,233,841 bytes，SHA-256 `c71f0ce00bec95b07744e116345e33d8cbbe08cef896382cf907bf4b51a2cd51` |
| tokens.txt | 315,894 bytes，SHA-256 `f449eb28dc567533d7fa59be34e2abca8784f771850c78a47fb731a31429a1dc` |

下載先寫 `.part`，校驗後才發布；重試沿用已驗證資產。npm 僅離線安裝剛下載並校驗的固定 tarball，禁用 lifecycle scripts／audit／fund 與可選相依的自動取得。準備流程依次是檢查、依賴、ASR、VAD、校驗、載入。完整準備後辨識程序不含網路請求；缺檔／損壞須手動修復，辨識不觸發下載。

### 安裝失敗與診斷

失敗時，主頁直接顯示失敗步驟、原因與可用的 HTTP 狀態，該步驟標為「失敗」，不沿用下載完成的 100%。按「詳細原因」會在同頁展開檔案／依賴名稱、當次來源、具體操作（下載／解壓／安裝／載入）、HTTP 狀態、系統碼、程序結束碼與底層訊息；「複製診斷」由使用者明確操作後複製這些資料。

錯誤保存在本機語音目錄的 `install-error.json`，程式重開仍可檢視；改選模型來源或語言不會把錯誤覆蓋成「等待安裝」。重試按鈕明確標示「重試安裝」，已驗證檔案可重用。安裝每個檔案前先發布正確步驟，避免 ASR 連線失敗卻仍標在執行環境。程序結束後再讀取一次最後狀態，沒有錯誤報告的異常結束則至少顯示程序結束碼。

區分 DNS、Proxy、逾時、TLS／憑證、HTTP、校驗、權限、依賴安裝與模型載入錯誤。診斷遮蔽使用者路徑、URL 憑證與 query，保留來源主機及必要錯誤碼。npm 使用私人快取，且依實際結束碼判定成功，不把 Windows PowerShell 對 stderr 的包裝當成安裝失敗。舊版只有 `download_failed` 而無細節時會明示未記錄，不能據此推斷具體原因。

## 背景工作與資料相容

主程式與 worker 以本機工作檔及進度檔通訊，不開放網路辨識 API。每次處理一通，CPU threads 固定為 2，等待佇列上限 1000 筆，只保存檔案描述而非音訊。背景程序在 kill-on-close Job Object 中，取消／退出時回收整個程序範圍，其他設定檔實例以同一命名 mutex 避免同時改寫共享語音環境。

來源只接受錄音根目錄內、非 reparse point 的已完成 WAV。worker 解析 RIFF chunks，接受 mono PCM16、8／16 kHz；8 kHz 使用持續的 2 倍線性插值適配，不能恢復原本不存在的電話高頻資訊。逐塊輸入連續 VAD，最長語音段 30 秒，第一次語音段補回最多 0.3 秒起始音訊。最長單檔 12 小時；不整檔載入音訊。保留粗略段落時間，沒有逐字對齊或說話人分離。

結果相鄰保存：

```text
recordings/2026-11-06/call.wav
recordings/2026-11-06/call.live.txt
recordings/2026-11-06/call.wav.transcript.json
recordings/2026-11-06/call.wav.transcript.txt
```

JSON 包含 schema、模型／引擎版本、來源 SHA-256、語言、狀態、時長、分段與全文。TXT 可直接閱讀；未完成時可能只含已完成段落，介面明確標示。每段完成後原子保存，可在來源／模型／引擎／語言相同時重試續作。完整轉寫前後校驗來源，不改寫 WAV。既有 flat／daily／weekly／custom 目錄、quality／title sidecar、根目錄 calls.csv 九欄契約不變。

設定獨立存在選定 INI 旁的 `.speech`，佇列為 `.speech-queue`，不修改連線草稿；兩者均已加入 Git 忽略。不要將模型、錄音、工作檔與個人設定加入版本控制。


## 即時 SenseVoice 與事後 Qwen3-ASR

僅 x64。左側以「即時字幕」「錄音轉寫」分為兩個模組。通話收到音訊後，右下角字幕框顯示「正在錄音」，SenseVoice 以 VAD 短段辨識並立即保存該段文字；錄音執行緒只通知開始／結束，不等待推論。掛斷後字幕框關閉。切到其他頁不取消工作。同時只能執行一個辨識工作，來電可中斷並重新排入背景歷史工作。正在安裝的環境不會被來電終止。無音訊時不宣稱正在錄音。多路通話仍正常錄音，未取得即時工作者的通話於掛斷後排隊。

在「即時字幕」安裝 SenseVoice，或在「錄音轉寫」選 Qwen3-ASR 大小後按安裝，兩者獨立安裝，不會因啟用或切換選項自動下載。Qwen 固定官方 `Qwen/Qwen3-ASR-0.6B-hf` revision `7f1569a48a89f3e3f4dc3a5c9d28bddd903bc76c`，模型檔案共 1,576,363,223 bytes；另有 Python 3.12.10、Transformers 5.13.0、PyTorch 2.9.1+cpu 與固定依賴，要求 6 GB 可用空間。資產 URL／SHA-256 全部編譯進程式，pip 只從已校驗的本地 wheels 安裝，推論強制離線、本機 safetensors、禁止 remote code。來源選擇僅影響 Hugging Face 模型，Python／PyPI／PyTorch 使用官方來源。

掛斷後，在歷史錄音右鍵開啟文字結果，在左側選擇 Qwen3-ASR，再按「開始轉寫」。也可選回 SenseVoice，兩版分開保存：

```text
call.live.txt
call.wav.transcript.json / call.wav.transcript.txt
call.qwen.txt / call.qwen17.txt
call.wav.qwen3asr.transcript.json / call.wav.qwen3asr.transcript.txt
```

Qwen 使用 CPU 4 threads、最多 20 秒一段，可能在段落邊界切斷詞句；不承諾一定優於 SenseVoice。它是使用者手動觸發的事後重轉，不會每次掛斷自動額外耗用 CPU。兩種工作都最多接受 12 小時錄音，原始 WAV 不變，部分完成結果會保留。Qwen 不做逐字時間對齊、說話人分離或文字合併，時間是輸入音訊段範圍。

國際化沿用簡中、繁中、English；模型名稱、穩定模型識別與磁碟格式不翻譯。ASR 語言選擇與 UI 語言獨立，預設／缺漏翻譯規則沿用原程式。

驗證：x86／x64 編譯、合成 growing-WAV 於掛斷前出字及尾段 drain、模型佇列隔離與復原、兩份結果切換、三語與最小視窗、Qwen 私有 Windows PowerShell 安裝依賴與實際 native imports、模擬推論中斷後續轉。未下載兩個模型的權重或處理真實錄音，實體話機雙向聲音、ASR 準確率及實際延遲仍待裝好模型後驗收。


### Qwen 大小選擇與電腦配置建議

「錄音轉寫」的模型與歷史結果版本選單現在都可選 Qwen3-ASR **0.6B／1.7B**。既有 `qwen` 設定、佇列、安裝目錄與 `.qwen3asr.transcript.*` 結果繼續代表 0.6B，不需要搬移。1.7B 使用 `qwen17` 身分、`qwen/models-1.7b` 與獨立的 `installed-1.7b-v1` 就緒標記；共用已校驗的私有 Python CPU 依賴。SenseVoice 即時模式不受大小選擇影響。

| 選項 | 固定模型檔案大小 | 安裝前可用空間 | 本產品 CPU 配置建議（估算） |
|---|---:|---:|---|
| SenseVoice INT8 | 約 241 MB | 1 GB | 近代 4 核 CPU、8 GB RAM |
| Qwen3-ASR 0.6B | 1,576,363,223 bytes，約 1.58 GB | 6 GB | 近代 4 核 CPU、16 GB RAM、SSD；建議先試此版本 |
| Qwen3-ASR 1.7B | 4,087,628,216 bytes，約 4.09 GB | 12 GB | 近代 8 核 CPU、32 GB RAM、SSD；事後轉寫耗時較長 |

以上是目前 Windows CPU／float32／單工作／20 秒分段方式的保守產品建議，**不是官方最低需求或效能實測**。顯卡不參與本版本推論，不能以 VRAM 取代系統 RAM。UI 顯示實體總 RAM 與邏輯處理器數，邏輯處理器數不等於實體核心數；不以此自動改選或禁止使用模型。實際用量／速度取決於 CPU、剩餘 RAM、音訊內容等，安裝空間門檻只檢查目標磁碟，不保證其他程式同時執行時有足夠 RAM。1.7B 不保證每段錄音一定更準確。

1.7B 固定官方 [Qwen/Qwen3-ASR-1.7B-hf](https://huggingface.co/Qwen/Qwen3-ASR-1.7B-hf) revision `bcd2b5b7f32b480ab5790554cfa8347f246a14f3`，safetensors 為 4,076,193,080 bytes，SHA-256 `2db53c7d81bd9b8cbc6a074e89be2c968a0d373fb4ee68bb1b1e14f7042dfee1`。0.6B 官方來源為 [Qwen/Qwen3-ASR-0.6B-hf](https://huggingface.co/Qwen/Qwen3-ASR-0.6B-hf)。所有推論檔案固定 revision／hash，只有使用者按安裝才下載；安裝 1.7B 不會覆寫 0.6B。下載器接受固定大小的 4 GB 以上檔案，仍以 SHA-256 與精確位元組數校驗。

1.7B 結果另存 `call.wav.qwen3asr-1.7b.transcript.json` 與 `.txt`；因此同一錄音可保留 SenseVoice、Qwen 0.6B、Qwen 1.7B 三份結果。不同模型不共用斷點。UI 沿用簡中、繁中、English，模型身分與結果檔名維持穩定 ASCII。

驗證新增：三種模型設定／佇列重啟保存、兩種 Qwen 就緒標記隔離、兩種大小結果互不覆寫、未知大小拒絕、三語最小視窗與結果版本切換、Windows PowerShell 的 1.7B RuntimeOnly 私有 CPU 依賴檢查。沒有下載 0.6B／1.7B 權重，本次未測實際辨識效能與準確度。

## 國際化與多語言交付

Windows 原生客戶端沿用簡體中文、繁體中文、English，首次語言與使用者語言來源不變，缺漏依既有 `[缺少文案]`／`[Missing text]` 顯示。所有設定、按鈕、語言選項、狀態及錯誤使用中央 `ui_resources.hpp` 的 `speech.*` keys。輸入法產品名使用系統顯示名，不翻譯。UI 語言切換不改變 ASR 語言，也不改變輸入法自己的辨識語言；ASR 支援 auto／zh／en／yue／ja／ko，第一版不保證中文結果的繁簡形式。模型原始標點與正規化結果保留，不偷偷增加另一套標點模型。技術 ID、雜湊、JSON keys、`wetype` 與數值時間獨立於地區顯示。
