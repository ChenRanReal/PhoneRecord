# 歷史通話重新命名

PhoneRecord 2.6.0 的「錄音資料」增加「通話名稱」欄位。可以為歷史紀錄設定容易辨識的名稱，例如「合約回訪」；名稱可搜尋，關閉程式後仍會保存。原始聯絡人及號碼另列，原始時間、錄音檔名、音訊、品質資料與台帳都保留。

## 操作

1. 選取一筆已完成的錄音，按「重新命名」或 F2。
2. 核對視窗上方的通話時間及原始號碼，輸入單行名稱，最多 120 個 Unicode 字元，支援中文、英文、符號與表情。
3. 按「保存名稱」。前後空白會移除，新名稱顯示在列表及該錄音的播放標題。
4. 按「取消」或關閉編輯視窗會放棄草稿。「還原原名」只清空輸入，仍需保存才套用；保存空白名稱會恢復以原始聯絡人或號碼顯示。

搜尋可用自訂名稱、原始聯絡人、號碼、日期或檔名。若搜尋的是舊自訂名稱，改名後該筆可能不再符合原篩選；清除搜尋或輸入新名稱即可找到。不同通話可以使用相同名稱，仍以原錄音檔識別，互不覆蓋。

## 保存與備份

自訂名稱保存在該錄音旁的 `<原錄音檔名>.title.json`，採 UTF-8。這是紀錄的附屬資料，複製或備份錄音時請一併保留；既有 `.quality.json` 等附屬資料也應保留。

程式以暫存檔完成寫入再替換名稱資料。失敗時保留既有資料，不將部分內容當成保存成功。取消、命名及還原不改動 WAV 或 `calls.csv`；原始通話資料仍可核對。技術日誌只記錄操作結果、檔案識別碼及錯誤代碼，不輸出自訂名稱。

## 無法保存時

| 提示 | 處理方式 |
|---|---|
| 名稱超過限制或含控制字元 | 縮短至 120 個字元，使用單行文字 |
| 錄音仍在寫入／被占用 | 等候該通話結束、檔案完成，或釋放其他寫入程式後重試 |
| 名稱已被其他操作修改 | 取消並重新開啟，核對最新名稱後再修改 |
| 無法讀取名稱資料 | 先備份損毀的 `.title.json`，再修復或移至其他位置；不要覆蓋未知內容 |
| 無法保存 | 確認原錄音存在、資料夾可寫、名稱附屬檔案不是唯讀；查看日誌的 Win32 代碼 |

正在編輯名稱時，錄音服務仍繼續執行；若要求程式退出，未保存的名稱草稿會取消。
