# PhoneRecord 2.3 快速上手

PhoneRecord（通話錄音工作台）在 Windows 電腦接收電話的錄音串流，通話接通後自動錄製、掛斷後保存，並提供內建播放與故障建議。一般使用不必手動開始或停止錄音。

這是需要配合話機設定的工具。已驗證的組合為 **Fanvil X3S／硬體 V1.1／韌體 2.4.7.9.1**。其他型號可先執行適配檢查；只支援 SIP 通話或具備本機錄音功能，並不足以保證相容。

## 1. 準備

- 可開啟電話管理網頁，並有權修改「網路錄音」及兩條通話 Action URL。網頁帳密由裝置管理員提供，與 SIP 分機帳密不同。
- 話機可連到這台 Windows 電腦。請確認網路允許事件與控制 TCP，以及音訊 UDP；公司網路可請管理員協助放行。
- 將 `PhoneRecord.exe` 放入自己可寫入的資料夾再執行，例如個人的文件資料夾。不要直接在壓縮檔或唯讀目錄內執行。

程式本身不需要 Python。可以只交付 exe，首次啟動會自動進入連接設定；不需要先有 `config.ini`。若偏好文字設定，可使用空白的 [config.example.ini](../cpp/config.example.ini)，複製並改名為 `config.ini`。

首次語言依 Windows 選擇，左下可隨時切換「简体中文／繁體中文／English」。程式內「說明與適配」可離線閱讀完整三語說明；選「首次設定：電腦與話機對照」可隨時回看以下步驟。

## 2. 先填電腦端

開啟「連接設定」，逐一填入自己的資料。點選欄位，下方會顯示用途與限制。

| 欄位 | 如何取得或填寫 |
|---|---|
| 話機 IPv4 | 從電話的網路狀態頁取得，是電話本身的位址 |
| 話機網頁埠 | 管理網頁的 HTTP 埠，通常 `80`；若管理員改過，填實際值 |
| 登入帳號／密碼 | 可存取電話錄音設定頁的網頁帳密 |
| 本機可達 IPv4 | 在 Windows「網路連線詳細資料」或 `ipconfig` 查看，選擇電話可達的網卡；不要使用回環位址或無關的 VPN／虛擬網卡 |
| TCP 控制埠 | 預設 `10000`，稍後要填入電話「錄音伺服器埠」 |
| 事件接收埠 | 預設 `18080`，稍後要填入兩條 Action URL；可改成未被占用的 1–65535 整數 |
| UDP 起始／結束埠 | 預設 `20000`–`20100`，用於接收音訊 |
| 外部觸發 | 一般自動錄音保持**未勾選**；僅已有外部控制器時使用 |
| 錄音保存目錄 | 選自己可寫入的位置；預設 `recordings` 位於設定檔旁 |

控制埠與事件埠是不同用途，不可相同；網頁埠是電話端的服務。事件埠不必使用 8080。

按「保存設定」後，在無通話時按左下 **「退出程式」**，再重新開啟 exe。**右上 X 預設只是收至系統托盤，並沒有退出／重啟**。連接與保存目錄修改需重啟才生效；語言、通知、關閉方式及健康檢查頻率另依介面提示立即套用。

## 3. 再填電話端

由程式按「打開話機網頁」，或在瀏覽器開啟電話管理網頁。下表以 Fanvil 網路錄音介面為例，選單名稱可能隨韌體不同。

| 電話的設定 | 應對應的值 |
|---|---|
| 啟用錄音 | 勾選／啟用 |
| 錄音類型 | `Network`（網路伺服器錄音） |
| 錄音編碼 | `PCMA` 或 `PCMU` |
| 錄音伺服器位址 | 軟體的「本機可達 IPv4」 |
| 錄音伺服器埠 | 軟體的「TCP 控制埠」，預設 `10000` |
| Call Established／通話建立 Action URL | 下方 `ev=est` 模板 |
| Call Terminated／通話結束 Action URL | 下方 `ev=end` 模板 |

```text
http://<PC_IP>:<EVENT_PORT>/event?ev=est
http://<PC_IP>:<EVENT_PORT>/event?ev=end
```

`<PC_IP>` 與 `<EVENT_PORT>` 是占位文字，請整段替換成自己的「本機可達 IPv4」與「事件接收埠」，不要原樣輸入尖括號。事件埠預設 `18080`，不等於錄音伺服器埠 `10000`。

在電話網頁保存／套用。只調整錄音相關欄位及這兩條回呼，保留其他公司設定。若目標事件已有公司用途，先由管理員安排事件轉送或其他控制方式，避免覆蓋原業務。

## 4. 檢查與驗收

1. 回到程式「運行概覽」，執行「本機檢查」與「話機檢查」。本機與話機燈應轉綠；紅燈時查看診斷建議。
2. 在「連接設定」或「說明與適配」按「適配檢查」。程式會唯讀核對錄音介面、啟用狀態、Network 模式、編碼、伺服器位址／控制埠與兩條回呼。它不會修改話機、不撥號，也不發送測試起停錄音。
3. 顯示「可進行通話驗收」代表讀取的設定符合要求。接通約 **20 秒真實通話**，請雙方輪流說話，再掛斷。
4. 到「錄音資料」找最新一筆，核對時間／號碼，雙擊或按「播放」，確認**雙方聲音都清楚**。掛斷後概覽應回到等待通話，上一通鏈路作為歷史結果保留。

| 適配結果 | 接下來做什麼 |
|---|---|
| 設定需修正 | 按逐項建議調整；軟體連接值變更後保存、退出、重開，再檢查 |
| 介面尚待適配 | 目前網頁欄位與已支援介面不同；提供品牌、完整型號、硬體與韌體，需進一步適配，不能直接判定硬體不支援 |
| 無法判定／無法讀取 | 確認連線、網頁埠、帳密與權限，無通話時重試 |
| 等待通話結束 | 先掛斷，避免檢查占用錄音所需的網頁請求 |
| 設定已修改，需保存／重啟 | 正在編輯的值與運行值不同；先完成保存與重啟 |
| 可進行通話驗收 | 完成上述真實電話與雙向試聽 |
| 新通話錄音鏈路已驗證 | 已看到檢查後的新通話完成控制、音訊及檔案；仍需人工確認雙方語音內容 |

適配檢查不會把以往的成功錄音當成本次結果，也不把合成測試音訊當成實機驗收。綠燈、HTTP 成功或訊號品質通過，都不能單獨取代雙向試聽。

## 5. 日常操作

程式運行時，正常接聽／撥打即可。電腦及程式必須持續運行；休眠、關機或退出期間無法接收錄音。

「連接設定 → 關閉視窗時」可選系統托盤、工作列最小化或直接退出。收起後可由托盤圖示重新開啟；左下或托盤的「退出程式」會真正結束程式。

**托盤氣泡預設關閉**。需要提示時勾選「顯示托盤氣泡通知」再保存；取消後保存即可靜默運行，不影響錄音、健康燈與日誌。

錄音資料提供內建播放／暫停／停止、拖曳進度、搜尋與定位檔案；不需要呼叫系統播放器。設定目錄不會自動搬移舊錄音。長期使用前可由管理員安排穩定的電腦位址，位址改變時需同步兩端。

## 6. 出問題時自己查

| 現象 | 先做這一步 |
|---|---|
| 本機燈紅／埠無法監聽 | 確認本機網卡、保存目錄及埠是否被占用；換事件埠時同步兩條電話回呼 |
| 話機燈紅／登入失敗 | 確認電話網頁是否能開啟、帳密及權限是否正確；換電腦後重新填密碼 |
| 接通後沒有起錄觸發 | 核對兩條 Action URL、事件埠、電話到電腦的連線及防火牆 |
| 有起錄但沒有音訊 | 核對 Network、PCMA／PCMU、伺服器位址／控制埠及 UDP 放行，再看鏈路停在哪一步 |
| 有檔案但沒聲音／單向聲音 | 播放最新檔案，核對來源及電話是否提供雙向混音；不要只看「已保存」 |
| 保存了設定卻沒變 | 按「退出程式」再重開；不要只按 X |
| 找不到程式視窗 | 查看系統托盤隱藏圖示；同一設定檔不需重複啟動多個實例 |

先在「診斷中心」選異常事件閱讀建議；需要協助時，複製適配報告或匯出診斷報告，附上品牌／型號／韌體與重現步驟。適配頁及適配報告不列實際 IP／回呼值；一般診斷報告仍包含技術環境資料。

更多欄位與機型能力見 [操作與機型適配](操作與機型適配.md)，穩定代碼及日誌說明見 [使用與排查](PhoneRecord_使用與排查.md)。

## 交給下一位使用者

交付 `PhoneRecord.exe`、本指南，以及可選的空白 `config.example.ini` 即可；完整三語說明已內建於 exe。讓對方填自己的裝置資料，不要把目前使用者的 `config.ini`、加密會話快取、日誌、通訊錄或錄音當成通用範本。加密密碼綁定原 Windows 使用者，換人／換電腦應自行重新輸入。
