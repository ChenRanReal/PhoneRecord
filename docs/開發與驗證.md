# 開發與驗證

目前產品為 C++ 原生 Windows 版本 **2.4.1**。一般使用者可下載 `cpp/PhoneRecord.exe`，依 [快速上手](快速上手.md) 設定，不需要安裝 Python。

## C++ 建置

在專案根目錄執行：

```powershell
cmd /c .\cpp\build.bat
```

目前驗證工具鏈為 Visual Studio Enterprise 18、MSVC 14.51.36231、Windows SDK 10.0.26100.0。不同安裝位置需先調整 `cpp/build.bat` 的 `MSVC`、`SDK`、`SDKV`；編譯選項為 C++17、x86、靜態 CRT。
既有 exe 可直接使用；Windows 7 API 編譯目標不代表已完成舊系統驗收。

圖示的 SVG、PNG、ICO 位於 `cpp/assets`，已內嵌於 exe；開發環境安裝 Pillow 後可執行 `py -3 tools/build_app_icon.py` 重建，產品執行不需要這些外部資產。

## 離線回歸

以下測試在 Windows 使用臨時設定、回環假話機與合成音訊，不讀取個人連接設定，也不會試打真實電話。開發環境已驗證 Python 3.13；GUI 測試與圖示重建需 Pillow。

```powershell
$env:PYTHONIOENCODING='utf-8'
$env:PYTHONUTF8='1'
py -3 -m pip install Pillow
py -3 tests/product_smoke.py --output docs/probe/local/core
py -3 tests/desktop_smoke.py --output docs/probe/local/desktop
py -3 tests/desktop_workflow.py --output docs/probe/local/workflow
py -3 tests/localization_smoke.py --output docs/probe/local/localization
py -3 tests/onboarding_smoke.py --output docs/probe/local/onboarding
py -3 tests/phone_setup_smoke.py --output docs/probe/local/phone_setup
py -3 tests/event_port_migration.py
```

測試涵蓋原生錄音核心 11 組、桌面基本操作 5 組、操作流程 9 組、三語／埠／說明 7 組及首次使用／適配／通知 6 組，另有話機自動設定 8 組測試及事件埠遷移保護 fixture。設定測試使用有狀態假話機驗證寫入、回讀、備份、復原、過期預覽、權限拒絕及其他公司回呼保留。
本機測試輸出寫入 `docs/probe/`，由 Git 忽略；輸出與現場診斷資料不同，提交時仍應檢查檔案清單。

## 選用的 Python 版本

`src/`、`web/` 與相關工具保留作為舊版實作與開發參考；日常使用建議 C++ 版本。兩個版本不可同時占用同一組埠。

Python 版本從根目錄的 `config.json` 讀取音訊／監聽設定。從 `config.example.json` 複製後，填入自己的 `advertise_ip`；話機網頁目標與認證改由環境變數提供，不再內嵌於程式碼：

| 環境變數 | 用途 |
|---|---|
| `PHONE_RECORD_PHONE_IP` | 話機網頁主機位址 |
| `PHONE_RECORD_PHONE_PORT` | 話機 HTTP 埠，預設 80 |
| `PHONE_RECORD_PHONE_USER` | 網頁登入帳號 |
| `PHONE_RECORD_PHONE_PASSWORD` | 網頁登入密碼 |

```powershell
Copy-Item config.example.json config.json
# Edit advertise_ip in your local config.json before starting.
$env:PHONE_RECORD_PHONE_IP=Read-Host 'Phone IPv4'
$env:PHONE_RECORD_PHONE_USER=Read-Host 'Phone web user'
$env:PHONE_RECORD_PHONE_PASSWORD=Read-Host 'Phone web password' -MaskInput
py -3 src/app.py --config config.json
```

Python 命令列工具亦可顯式指定主機／使用者。缺少目標或帳號時會先停止；日誌只記錄請求中繼資訊，不輸出 cookie 或完整認證請求。
此環境變數流程只適用 Python 版；C++ 仍由自身設定頁保存並加密密碼。
