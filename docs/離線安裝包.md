# 離線安裝包

無法在安裝後連線下載語音模型時，使用離線壓縮包。標準執行檔維持現況：模型仍由使用者在程式內按「安裝模型與環境」後下載。x86 沒有語音功能，因此沒有離線變體。

## 變體

| 變體 | 檔名 | 內容 | 是否放入 GitHub Release |
|---|---|---|---|
| 標準 | `PhoneRecord.exe`、`PhoneRecord-x64.exe` | 只有程式。SenseVoice / Qwen 仍按需下載 | 是 |
| 離線 SenseVoice | `PhoneRecord-x64-offline-sensevoice.zip` | x64 程式、Node、sherpa-onnx、SenseVoice INT8、Silero VAD、授權 | 是。權重約 241 MB，整包遠低於 2 GiB |
| 離線 Qwen 0.6B | `PhoneRecord-x64-offline-qwen06.zip` | x64 程式、私有 Python CPU 環境、Qwen3-ASR 0.6B | 僅當成品小於 2 GiB。權重本身約 1.58 GB，預期可以，超過則略過上傳並留下 `.skipped.txt` |
| 離線 Qwen 1.7B | `PhoneRecord-x64-offline-qwen17.zip` | 1.7B 權重與執行環境 | 否。`model.safetensors` 為 4,076,193,080 bytes，單一檔案已超過 GitHub Release 每個資產 2 GiB 的上限。腳本可在本機做出壓縮包，供隨身碟散發 |

不把 SenseVoice 與 Qwen 0.6B 合成一個資產：兩者相加會貼近或超過 2 GiB。需要兩者都離線時，分別解壓後把其中一個 `bundled-speech\qwen` 目錄併入另一個 `bundled-speech`，並把 `bundle.txt` 的對應旗標改為 `1`。自動更新若修補模型包，會整個換掉 `bundled-speech`，手動合併的第二個模型可能被覆蓋。

壓縮包頂層是一個資料夾，內含 `PhoneRecord-x64.exe`、`install-variant.txt`、`離線安裝說明.md` 與 `bundled-speech\`。模型不進入 Git；打包時下載到快取並用 `cpp/offline_rules.hpp` 的長度與 SHA-256 核對。

## 執行時如何選模型

程式在執行檔旁邊尋找 `bundled-speech`。

- 目錄不存在：與現在相同，模型在 `%LOCALAPPDATA%\PhoneRecord\speech-v1`，只有使用者按安裝才下載。
- 該模型的權重長度與 SHA-256 都符合編譯進程式的固定值，且 Node 或 Python 執行環境在場：直接使用這份，不再下載。
- 目錄宣稱含有該模型，或已經有部分權重，但校驗失敗：視為損壞，顯示既有的校驗失敗，**不會**改走網路下載。刪除整個 `bundled-speech` 後才會恢復按需下載。
- 離線包沒有帶上的另一個模型（例如 SenseVoice 包裡的 Qwen）仍可在有網路時另行安裝。

首次啟用語音時在背景計算 SHA-256。之後若檔案大小與修改時間未變，沿用本機快取，避免每次啟動重算 1 GB 以上的權重。

## 自動更新

兩個變體共用同一份已簽章的執行檔清單（`update-manifest.txt` / `update-manifest-x64.txt`）。簽章格式、公鑰與執行檔 64 MB 上限都沒有改。離線壓縮包用另一份 `PhoneRecord-modelpack-v1` 清單，副檔名為 `update-manifest-x64-offline-sensevoice.txt`（Qwen 0.6B 同理）與對應的 `.sig`，同樣用現有 RSA 公鑰驗證。舊版用戶端不讀這些新檔，因此不會把模型包誤當成執行檔。

`install-variant.txt` 記錄變體。更新程式只替換執行檔，不刪除 `bundled-speech` 或變體檔。本機權重長度仍符合時，不下載模型包。長度不符或目錄遺失時，才會嘗試下載該變體的壓縮包；Release 上沒有這個資產、簽章失敗或下載失敗時，執行檔更新仍完成，已存在的模型目錄保持不動。模型包在新版程式成功啟動後才解壓替換，失敗的執行檔回滾不會先刪掉模型。

Qwen 1.7B 沒有 Release 資產。本機若已放好且校驗通過，更新不會強迫重新下載。

## 授權

離線包的 `bundled-speech\licenses\` 必須隨包散發：

- SenseVoiceSmall：FunASR 模型授權（須保留來源、作者與模型名稱）
- Silero VAD：MIT
- Qwen3-ASR 0.6B / 1.7B：Apache-2.0
- sherpa-onnx：Apache-2.0；ONNX Runtime：MIT；Node.js 授權在 node 目錄內

虛擬聲卡驅動不在任何安裝包內，也不會因本變更改寫 Windows 預設音訊裝置。

## 如何建置

標準執行檔：

```powershell
cmd /c cpp\build.bat
pwsh -File tools/Build-Desktop.ps1 -Architecture x64 -OutputDirectory tmp/desktop-x64
```

離線包（會下載模型到 `tmp/model-cache`，不會寫入 Git）：

```powershell
pwsh -File tools/New-OfflinePackage.ps1 -Variant sensevoice -Executable tmp/desktop-x64/PhoneRecord-x64.exe -OutputDirectory tmp/offline -CacheDirectory tmp/model-cache
pwsh -File tools/New-OfflinePackage.ps1 -Variant qwen06 -Executable tmp/desktop-x64/PhoneRecord-x64.exe -OutputDirectory tmp/offline -CacheDirectory tmp/model-cache
pwsh -File tools/New-OfflinePackage.ps1 -Variant qwen17 -Executable tmp/desktop-x64/PhoneRecord-x64.exe -OutputDirectory tmp/offline -CacheDirectory tmp/model-cache
```

`-Publish` 會套用 Release 規則：SenseVoice 必須成功且小於 2 GiB；Qwen 0.6B 超過上限或磁碟不足時寫出略過說明並成功結束；Qwen 1.7B 直接略過、不下載。正式簽章由 `tools/New-ModelPackManifest.ps1` 在已有 `UPDATE_SIGNING_KEY` 時產生，不取代執行檔清單。

檢查規則與固定雜湊（不下載模型）：

```powershell
pwsh -File tools/Test-OfflineRules.ps1
```

## 國際化與多語言交付

此變更不新增介面字串、語系或預設語言。校驗失敗沿用既有 `speech.integrity`（簡體中文、繁體中文、English）。模型識別、檔名、雜湊與變體 ID 維持 ASCII。本文件為繁體中文建置說明，不改變介面缺漏翻譯的行為。

## 尚未在實體離線 Windows 驗證

規則、固定雜湊與變體選擇已由可攜測試覆蓋。尚未在斷網的 Windows 機器上解壓離線包、冷啟動辨識，或讓自動更新實際下載並替換模型包。Qwen 0.6B 成品是否低於 2 GiB，要等 CI 打出壓縮包後才有確切位元組數。
