# 介面精簡與設定分類

## 首次使用

「連接設定」預設進入「基本設定」，只顯示話機 IP、話機網頁帳密、錄音保存目錄及唯讀本機接收位址。帳號不要求管理員身分，仍須具備實際錄音設定與 Start／Stop 權限。

「進階設定」包含網頁埠、本機位址、控制與事件埠、UDP 範圍、空閒逾時、健康檢查與外部觸發，以及固定 IP／DHCP 尋址方式。MAC 只在 DHCP 模式顯示，切回固定 IP 不清除 MAC 草稿。

「偏好設定」包含通知、關閉視窗方式與開機啟動。分類切換只改變顯示，不重建輸入框、不保存或重載配置。保存時會保留全部分類的值；驗證失敗時自動開啟錯誤欄位所在分類。

## 日常使用

- 概覽、設定及說明頁共用「檢查連線與設定」，依既有唯讀適配流程核對本機、登入與話機設定；不試打電話或發送 Start／Stop。
- 概覽只顯示近期 WARN／ERROR 的處理摘要，無異常時明確提示。完整事件、穩定代碼及技術資料仍在診斷中心，雙擊異常摘要可開啟診斷。
- 錄音資料常駐「播放」「重新整理」。右鍵選單提供播放、重新命名、檔案位置、開啟資料夾及訊號分析；保留雙擊播放與 F2 重新命名。

## 驗證

使用隔離的離線程式與合成錄音，驗證三語分類、最小視窗尺寸、草稿保留、錯誤定位、隱藏值保存、固定／DHCP 切換、右鍵選單與 F2。使用既有首次使用、歷史命名及桌面流程回歸檢查相容性。不操作實體話機或個人配置，亦不自動切換使用者目前運行的版本。

## 國際化與多語言交付

保留簡體中文、繁體中文、English。分類名稱、帳密說明、合併檢查標籤、異常摘要與右鍵提示均提供三語。沿用 Windows 首次語言及左下使用者選擇，缺漏資源仍明確標示；語言切換不保存連接草稿或重建錄音會話。操作 PDF 採繁體中文。

## 次要操作收納

- 概覽保留直接檢查；話機網頁與設定指南在「更多操作」。
- 設定保留保存；一鍵設定只在基本分類顯示，檢查／話機網頁／指南在「更多操作」。
- 診斷保留複製報告；匯出與日誌目錄在「更多操作」。
- 說明頁只有檢查報告主題顯示檢查與複製按鈕。
- 更新偏好使用帶勾選狀態的原生選單，立即獨立保存；下載只在有新版本且未下載時顯示，安裝只在驗證完成的下載就緒後顯示。通話與背景工作中的安裝限制保留。

原生更多操作按鈕可用 Tab 與 Enter／Space 開啟。選單取消不執行操作；無可用話機地址或檢查忙碌時禁用相應項目。選單沿用原指令處理，不更動錄音或話機設定流程。新增 action_menu_smoke.py 驗證三語選單項目、顯示條件與草稿隔離；更新 UI 測試改走偏好選單指令。
