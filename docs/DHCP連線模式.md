# 固定 IP 與 DHCP 自動追蹤

## 使用流程

介面只有「固定 IP」與「DHCP（自動追蹤 IP）」兩種模式。舊設定未指定模式時維持固定 IP。

1. DHCP 首次在話機上查看目前 IP 與 MAC，填入程式，以及既有網頁登入、電腦可達位址與錄音埠。
2. 儲存後使用「退出」，再開啟程式；關閉視窗通常只會隱藏到系統匣。
3. 執行「一鍵設定話機」，檢視變更並確認。程式自動判斷是否直連；同網段首次登入時核對 MAC，跨路由器使用明確提供的 IP 登入並記錄使用者提供的 MAC，無法用 ARP 遠端證明其 MAC。
4. 整份設定成功回讀後建立配對。後續不必區分同網段／不同網段，不需 DNS、手動找新 IP 或重複核對 MAC。

設定檔使用 `phone_address_mode=fixed|dhcp`、`phone_ip` 及 `phone_mac`。IP 是首次明確提供的地址，新 IP 另行保存，不會覆寫原設定。MAC 接受冒號、連字號或無分隔符格式。DHCP 必須啟用內建回呼接收埠，不能關閉監聽。

## 一鍵設定及換址

一鍵設定保存錄音伺服器位址及控制埠，並設定四個回呼：

| 話機欄位 | 用途 |
| --- | --- |
| `AURL_CallEstablished_RW` | 通話建立、觸發錄音 |
| `AURL_CallTerminated_RW` | 通話結束、停止錄音 |
| `AURL_SetupCompleted_RW` | 啟動完成、回報目前位址 |
| `AURL_IpChange_RW` | IP 變更、回報新位址 |

已唯讀確認目前話機提供上述欄位。[Fanvil 官方 Action URL 規格](https://fanvil.com/downfile.aspx?id=7556)亦列出啟動完成與 IP 變更事件。實際設定仍檢查韌體頁面；缺欄位或已有不相干公司回呼時拒絕覆蓋，不猜測或默默降級。

程式產生隨機配對憑證加入回呼網址；這是內部核對，不需使用者後續操作。憑證草稿在預覽時先安全保存，設定成功回讀後才啟用。預覽及診斷不顯示憑證或完整回呼網址。

話機換址後，程式核對配對憑證，使用實際 TCP 來源 IP 更新目標，不相信參數宣稱的 IP，也不因 MAC 文字相同而信任陌生來源。HTTP 回覆完成並關閉連線後才排入工作，避免話機等待回覆時又收到程式的網頁請求。

切換由既有唯一命令執行緒處理，現有 HTTP 操作先完成；正在進行的通話及控制會話保留原目標，待安全邊界再切換。新目標登入會清除舊 Cookie 及就緒快取，並自動完成一次唯讀適配檢查。配對後沒有 MAC 掃描、DNS 查詢或週期 MAC 重驗；既有健康檢查設定不變。

## 配對保存與回復

憑證、配對狀態及最後接受的 IP 放在所選設定旁的 `<設定檔>.pairing`，由目前 Windows 帳戶的 DPAPI 加密並原子替換。配對及暫存檔已排除於 Git，不得放進發布包。重開會沿用最後的新 IP 及配對，不回頭登入首次 IP。

配對綁定首次 IP、MAC、登入帳號、網頁埠及本機錄音／回呼目的地。變更這些資料、更換話機、遺失配對檔或更換 Windows 使用者時，需以目前 IP 重新一鍵設定。電腦本身換 IP 後，話機保存的舊服務位址亦需重新設定。回復話機備份會停用本機配對，再配對後才恢復追蹤。回復舊方式可選固定 IP，填入實際位址，儲存退出後重開。

## 使用條件與實機驗收

話機新網段仍須能連到保存的電腦位址，電腦也須能連到話機網頁埠；錄音控制 TCP 與 RTP UDP 埠須互通。此功能不建立路由、DNS 或 DHCP 服務，不變更話機 DHCP／VLAN 或電腦防火牆。NAT／代理若改寫來源為閘道，不保證能直接反向登入話機。

程式未運行時的回呼可能遺失。重開先使用最後保存的 IP；若話機其間再換址，下一次有效的啟動、IP 變更或通話事件會帶入新位址。若到通話接通才收到新 IP，重新登入仍可能漏掉開頭，不保證換址期間錄音不中斷。

原生及 loopback 測試涵蓋配對加密保存、錯誤憑證拒絕、依實際來源換址、重開保留新 IP、配對後不重驗 MAC，以及新 IP 的 TCP 控制與 RTP 錄音。實體話機已做欄位唯讀查證；真正 DHCP 換址、跨 VLAN 雙向可達及通話聲音仍待現場驗證。本次未更改實體話機或個人設定。

驗證入口：`tools/Test-PhoneAddress.ps1`、`tests/phone_address_ui_smoke.py`、`tests/phone_pairing_smoke.py`，搭配既有錄音、話機設定與多語言回歸。

## 國際化與多語言交付

原生 Windows 客戶端沿用簡體中文、繁體中文、English。模式、MAC 提示、配對及換址說明、預覽欄位與失敗提示使用既有 `ui_resources.hpp`。預設語言、選擇來源、持久化及所選語言的缺漏提示維持既有行為，不新增語系。設定及協定使用穩定值 `fixed`、`dhcp`，不以翻譯文字判斷。

驗收包含兩模式三語切換、草稿保留、IP／MAC 必填、欄位啟用狀態、儲存重開、內嵌說明及長文字顯示。使用文件採繁體中文。
